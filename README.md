# olabiyi-portfolio

My personal site, live at https://olabiyi-portfolio.vercel.app. It has the products I've built, a couple of write-ups from my day job, and my data projects.

Built with Next.js 16 (App Router) and TypeScript, plain CSS, no UI library. All the copy lives in `app/content.ts`, so updating the site is mostly editing that one file.

## Running it

```bash
npm install
npm run dev
```

Then open http://localhost:3000. It's a static page, so it deploys to Vercel with the default settings.
